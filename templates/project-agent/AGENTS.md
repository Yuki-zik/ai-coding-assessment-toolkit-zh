# Agent 操作指南

## 会话开始时的必做步骤

1. 仅读“最新窗口”：`agent/tasks.md` 当前任务段 + `agent/timeline.md` 顶部最近 3-5 条
2. 总结当前状态
3. 在开始主要工作前更新任务
4. 可拆分的独立任务优先并行交给子 agent（写入范围必须不重叠）

仅当最新窗口不足时，才回溯旧记录或读取 `agent/project.md`。

## 子 Agent 推理强度

- `low`：检索、摘录、证据收集
- `medium`：常规实现与验证
- `high`：跨模块修改、疑难缺陷定位
- `xhigh`：架构/安全关键决策（默认）

先使用最低可行强度，质量不足再升级。

## 会话结束时的必做步骤

1. 更新任务
2. 在时间线里补一条带有 `Motivation` 的记录
3. 提出一条 Conventional Commits 风格的提交信息
